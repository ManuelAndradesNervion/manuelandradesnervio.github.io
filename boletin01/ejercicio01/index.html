Los pasos necesarios para realizar un commit y push en Git son los siguientes:

  1. Guardamos el código que estémos realizando.
  2. En el apartado de GitHub del programa o en GitHub Desktop en su defecto, comentamos el commit.
  3. Una vez realizado el commit, pulsamos el push.

A continuación voy a definir algunos términos que vamos a ver con frecuencia en el curso:

- HTML
HTML es el lenguaje estándar utilizado para crear y estructurar el contenido de las páginas web.
- CSS
CSS es un lenguaje declarativo que se utiliza para definir la apariencia visual y la maquetación de los documentos escritos en HTML o XML
- DOM
DOM es una interfaz de programación que representa las páginas web (HTML o XML) como un árbol jerárquico de objetos y nodos.
